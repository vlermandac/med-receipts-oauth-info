Personal-use application

Med Receipts rclone

A private Google Drive connection for organizing receipt documents on the account owner's computer.

What it does

The owner uses rclone to mount a Google Drive folder as a local directory. Authorized local tools can read incoming documents, prepare files, and save organized results back to that folder.

Google Drive access

The connection requests permission to read and write Drive files so it can handle files uploaded from the owner's phone and organize processed documents. Although the requested Google permission covers Drive files, this installation is configured to use one workflow folder.

This application is for its owner's personal use. It is not a public service and does not accept other users or document uploads through this website.
